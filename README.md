# 🐉 تعلم اللغة الصينية — بالعربية (إمبراطورية المندرين)
### Mandarin Chinese Learning Platform & Empire Conquest

منصة تعليمية تفاعلية متكاملة لتعلم اللغة الصينية المعيارية مباشرة **باللغة العربية الفصحى** دون الحاجة إلى لغة وسيطة (كالإنجليزية)، مصممة لتعمل بسلاسة على بيئات Linux و Android (Termux) والحواسيب الشخصية مع خادم مدمج ونفق سحابي عالمي عبر **Cloudflare**.

---

## ✨ المميزات الرئيسية

### 1. 🗺️ خريطة إمبراطورية المدن الصينية (`map.html`)
- **26 مدينة استراتيجية** مقسمة إلى 3 مستويات:
  - **المستوى الأول (المدن الإقليمية والتأسيسية):** سوتشو، داليان، شيامن، تشينغداو، هاربين، غويلين...
  - **المستوى الثاني (عواصم المقاطعات الكبرى):** تشنغدو، ووهان، شيآن، هانغتشو، نانجينغ، تشانغشا...
  - **المستوى الثالث (المدن المركزية العظمى):** بكين، شانغهاي، قوانغتشو، شنتشن، تشونغتشينغ، تيانجين.
- **تلوين الإمبراطورية:** صبغ المقاطعات والمدن بلون اللاعب الخاص فور امتلاكها.
- **درع التحدي وقوة الحصن:** مؤشر نقاط التحدي على قمة كل مدينة مع إمكانية تحصينها.
- **إطلاق أسماء عربية مخصصة:** إمكانية إطلاق أسماء باللغة العربية الفصحى حصرياً، وتوثيق اسم اللاعب الذي سماها علناً.
- **العملات من الاختبارات فقط:** تكلفة التسمية 50 عملة، ولا يمكن كسب العملات إلا باجتياز اختبارات الحفظ والقراءة في صفحة الاختبارات.

### 2. 🔐 حساب سحابي عبر Google Authenticator (OTP) بدون كلمة مرور
- مصادقة سحابية متوافقة 100% مع معيار **RFC 6238 TOTP** المعتمد في تطبيق **Google Authenticator**.
- **دخول فوري بدون كلمة مرور:** توليد مفتاح Base32 ورمز QR، وتسجيل الدخول عبر كود الـ 6 أرقام فقط.
- **ملف شخصي موحد عبر كل الصفحات:** نفس الرصيد من العملات، والـ XP، والحروف المتقنة، والأوسمة متزامن تلقائياً عبر جميع صفحات التطبيق الثمانية.

### 3. 🧗‍♂️ سلّم HSK ومحطات الطلاقة الحقيقية (`dashboard.html`)
- تتبع دقيق وصارم للحروف المتقنة ومقارنتها بسلّم HSK 3.0:
  - HSK 1: 174 حرفاً ── HSK 2: 347 ── HSK 3: 617 ── HSK 4: 1,064 ── HSK 5: 1,685 ── HSK 6: 2,663 ── الطلاقة: 3,500+ حرف.
- نظام ترقية الأوسمة لـ 3 مستويات (التأسيس ➔ الباحث المتقدم ➔ تنين المعرفة).

### 4. 🎯 5 أوضاع اختبار تفاعلية وكسب العملات (`tests.html`)
- اسمع واختر 🎧، اقرأ واختر 👁️، تذكّر 🧠، اكتب الحرف ✍️، والوضع المختلط 🎲.
- تمنح كل إجابة صحيحة **+5 عملات إمبراطورية 🪙**، والجولة المثالية **+25 عملة**.

### 5. 🔥 التحديات اليومية ورادار الأخبار الحية (`daily.html`)
- املاء الفراغ في تراكيب الجمل الصينية مع دعم نطق Web Speech API الصوتي الذكي.
- رادار 60s لجلب أخبار حقيقية وحكمة اليوم لحظياً من الإنترنت.

### 6. ✍️ مرسم الحروف الصينية (`writing.html`)
- ترتيب الخطوط السليمة (Stroke Order) ورسم الحروف على شبكة الخطاطين مع تفكيك الراديكالات والقصص التوضيحية لـ 77 حرفاً متوفراً محلياً بدون إنترنت.

### 7. 🎧 مدرب النطق الصوتي الأصلي والنبرات (`audio.html`)
- تدريب صوتي مع ملفات MP3 مسجلة بأصوات ناطقين أصليين وتوضيح دقيق لنظام النبرات الأربعة.

## 🚀 التثبيت والتشغيل السريع (Quick Start)

### 1. استنساخ المستودع (Clone)
```bash
git clone https://github.com/<your-username>/mandarin-arabic-empire.git
cd mandarin-arabic-empire
```

### 2. التثبيت التلقائي (Install)
يقوم السكربت بفحص Node.js و cloudflared وتجهيز كافة مجلدات البيانات والخرائط تلقائياً:
```bash
./install.sh
```

### 3. التشغيل (Run)

#### الخيار أ: تشغيل محلي (Local):
```bash
./start.sh
```
افتح المتصفح على: `http://localhost:8080`

#### الخيار ب: تشغيل مع نفق عام عالمي عبر Cloudflare (HTTPS):
```bash
./start.sh --tunnel
```
سيقوم السكربت بتوليد رابط عام فوري مشفر بصيغة:
`https://xxxx.trycloudflare.com`
يمكنك فتحه مباشرة من هاتفك، ومسح رمز Google Authenticator، وبدء المنافسة مع أي شخص في العالم!
